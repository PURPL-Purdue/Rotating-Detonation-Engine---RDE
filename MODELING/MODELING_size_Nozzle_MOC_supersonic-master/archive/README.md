# Archived reference code

These files were moved out of the active model, not discarded. The archive retains the original `src2` nozzle program, its root driver, unrelated HADES sizing functions and autosaves, and previous CEA input/output files. Their relative layout is preserved where possible. Archived programs may require their original working directory and are not dependencies of `MoC_Main_Model`.

`MoC_Solve_Field.m` and `MoC_March_Products.m` preserve the initial straight-boundary implementation used to diagnose the downstream contact-pressure mismatch. They are development references, not active entry points.
